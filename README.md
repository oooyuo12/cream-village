# Cream Village

반려견 산책 경로를 지도 기반으로 다루는 웹 프로젝트입니다.

기존 `dog-route-map` 프로토타입에서 시작해
UI와 기능을 개선한 버전입니다.

## Live Demo

https://cream-village.vercel.app

## Tech Stack

- React
- TypeScript
- Vite
- Leaflet / React-Leaflet
- Tailwind CSS
- Express
- Google GenAI
